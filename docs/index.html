Get Started in Seconds

Choose your preferred installation method

📦 NPM

npm install -g glimx

🔧 Bun

bun install -g glimx

⚙️ Configure Free Models

# Get free API keys
export GROQ_API_KEY="your-key"
export OPENROUTER_API_KEY="your-key"

# Run with free model
glimx --model groq/qwen-32b
